# Flux.2 Klein

Flux.2 Klein 9B系のComfyUI環境を管理する場所です。

## フォルダ

```text
normal/      通常生成用
nsfw/        NSFW生成用
pixelart/    ピクセルアート生成用
```

## 注意

Flux.2はKlein 9B前提です。
Flux.1系とは完全に別アーキテクチャとして扱います。
setup、workflow、download_listをFlux.1と混ぜないでください。
