# SDXL

SDXL系のComfyUI環境を管理する場所です。

## 元ZIP

```text
sdxl_chibi_pixelart.zip
```

## 構成

```text
chibi/       SDXL Chibi用
pixelart/    SDXL PixelArt用
```

## 確認済みファイル

```text
setup_sdxl.ipynb
backup_sdxl.ipynb
download_list_sdxl.txt
download_ui.ipynb
download_extra.ipynb
sdxl_chibi_24GB_workflow_v1.json
sdxl_pixelart_24GB_workflow_v1.json
comfyui_sdxl_chibi.html
comfyui_sdxl_pixelart.html
```

## 判断

setup、backup、download_listはSDXL共通。
workflowとHTMLはChibi用、PixelArt用で分かれます。
