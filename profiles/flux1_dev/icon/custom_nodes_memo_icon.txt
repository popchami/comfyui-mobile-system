# custom_nodes_memo_icon.txt
# Kick×Kickアイコン生成（flux1_dev/icon）に必要なカスタムノード整理
# 更新日: 2026-07-08

## 結論
icon構成では ComfyUI-OllamaGemini は使わない。
そのため、OllamaGemini由来の BRIA_RMBG / ConvertRasterToVector / SaveSVG 前提は撤回する。

現時点の安全な動作対象は PNGアイコン生成 まで。
SVG化・背景透過は、別途「使用するノード」を確定してから追加する。

## icon構成で使う前提のノード
- ComfyUI標準ノード
  - UNETLoader
  - DualCLIPLoader
  - VAELoader
  - EmptyLatentImage
  - CLIPTextEncode
  - FluxGuidance
  - KSampler
  - VAEDecode
  - UpscaleModelLoader
  - ImageUpscaleWithModel
  - SaveImage
  - LoadImage / VAEEncode（i2i用）

- 追加カスタムノード
  - comfyui-ollama
    - OllamaConnectivityV2
    - OllamaGenerateV2
  - ComfyUI-Custom-Scripts
    - ShowText|pysssss
  - ComfyUI-Manager
    - カスタムノード管理・更新用

## 使わないもの
- ComfyUI-OllamaGemini
- BRIA_RMBG
- ConvertRasterToVector
- SaveSVG

## 修正理由
既存workflow JSONには BRIA_RMBG / ConvertRasterToVector / SaveSVG が残っていたが、properties上で cnr_id が comfyui-ollamagemini になっていた。
ユーザー方針では OllamaGemini は使わないため、この経路は不採用。

## 今後SVG化する場合
SVG化を復活させる場合は、以下の順番で進めること。

1. 使用するSVG変換ノードを先に決める
2. RunPod上で /object_info を確認する
3. API形式の class_type / inputs を確認する
4. comfyui_icon_mobile.html に追加する
5. 生成PNG → 背景透過 → SVG保存 の順で実機検証する

## 現在のicon仕様
- 1024×1024で生成
- 4x-UltraSharpでアップスケール
- SaveImageでPNG保存
- 日本語入力はOllamaで英語化
- 固定スタイルは「flat design app icon」系
- 背景透過・SVG保存は未実装扱い
