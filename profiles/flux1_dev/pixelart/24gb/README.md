# Flux.1 Dev PixelArt 24GB

Flux.1 Devを使ったPixelArt用24GB環境です。

## 元ZIP

```text
flux1dev_pixelart.zip
```

## 確認済みファイル

```text
pixelart_24GB_workflow_v1.json
setup_pixelart.ipynb
backup_pixelart.ipynb
download_list_pixelart.txt
comfyui_pixelart.html
download_ui.ipynb
download_extra.ipynb
```

## 役割

- `setup_pixelart.ipynb` : RunPod上でComfyUI環境を構築する
- `backup_pixelart.ipynb` : 環境バックアップ用
- `download_list_pixelart.txt` : 必要モデル・追加ファイルのリスト
- `pixelart_24GB_workflow_v1.json` : PixelArt 24GB用Workflow
- `comfyui_pixelart.html` : スマホ操作用HTML UI
- `download_ui.ipynb` : UI系ダウンロード用
- `download_extra.ipynb` : 追加ファイルダウンロード用

## 注意

Flux.1通常版とは別のPixelArt専用環境として扱います。
